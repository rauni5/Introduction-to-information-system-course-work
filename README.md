# Business Website Project

## Overview

A multi-page website developed as part of the Introduction to Information Systems module. The website demonstrates web design principles, user experience considerations, and frontend development skills.

- Multi-page website
- Portfolio pages
- Product pages
- Blog pages
- Contact page
- Responsive design elements

## Technologies Used

- CSS3
- JavaScript

## Pages Included

- Home
- About Us
- Products
- Blog
- Contact
- Research
- Team Portfolio

## Learning Outcomes

- Web development fundamentals
- User interface design
- Website navigation
- Frontend development
- Content organization
